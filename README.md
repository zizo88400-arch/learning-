# الزوز علامة الملك 👑

إصدار أولي لمنصة تعليمية عربية للطلاب والمعلمين، باستخدام Flask وPostgreSQL.

## تشغيل محلي
- Python 3.11+
- `pip install -r requirements.txt`
- انسخ `.env.example` إلى `.env` واضبط المتغيرات.
- `python app.py`

## قبل النشر على Vercel
1. أنشئ قاعدة PostgreSQL خارجية ودائمة، وضع رابطها في `DATABASE_URL`.
2. اضبط `SECRET_KEY` بقيمة عشوائية قوية.
3. اضبط `ADMIN_PHONE` برقم مدير المنصة المصري.
4. اضبط Twilio لإرسال رسائل OTP. من دون إعداد Twilio لن يعمل تسجيل الدخول بالرسائل.
5. أضف `ANTHROPIC_API_KEY` لتشغيل المساعد الذكي.
6. ارفع الملفات إلى GitHub، واربط المستودع بـ Vercel، وأضف متغيرات البيئة في إعدادات المشروع.

## حدود الإصدار الحالي
- الكتب والملازم تُضاف كرابط خارجي؛ رفع الملفات مباشرة يحتاج خدمة تخزين خارجية.
- محتوى YouTube يضاف حاليًا كرابط من المعلم/المدير؛ بحث YouTube API يحتاج إعدادًا إضافيًا.
- الاختبار المنشأ من لوحة المدير يحتوي سؤال اختيار من متعدد واحد في هذا الإصدار الأول.
- لا تستخدم SQLite لتخزين دائم على Vercel.
- راجع حماية البيانات والخصوصية وسياسات الاستخدام قبل فتح المنصة للجمهور.
